# THE BÀTÁ · BTA

> A sphere of **UD0** — the ROOT0 universe / biosphere. Domain: **HERMES**.

THE BÀTÁ (BTA) — ìlù bàtá, the mouthpiece of Ṣàngó: a FIXED-head drum that cannot bend pitch like the [[talking-drum-dundun]], so it cannot imitate speech — instead it ENCODES it. Yorùbá is first disguised into a secret language, ẹ̀nà (the rule: echo every vowel onto a 'g' syllable, copying its tone — Yorùbá → Yogorùgùbágá), and only then struck. ⚑ It is literally a COMPILER (Villepastour modelled it with a computer scientist exactly so): Yorùbá = the source language, ẹ̀nà = the intermediate representation, the bàtá strokes (sharp L/M/H heads) = the target machine code — David's whole purple-paper compiler thread, in goatskin. Live: tap the strokes + the /r/ flam, run the ẹ̀nà cipher on any word, and watch the source→IR→strokes pipeline. Two-layer HONEST: the ẹ̀nà vowel-echo game and the bàtá's fixed unequal heads / Ṣàngó-Àyàn ritual context are real; the spoken ẹ̀nà game and Villepastour's ẹnà-bàtá stroke code are siblings not identical; a real ensemble runs up to three bàtá speaking this code at once; the voice is a synth, the tradition sacred and living. Plays as the ciphered layer of [[the-procession]].
